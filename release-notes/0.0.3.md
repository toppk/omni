# Omni v0.0.3

## Features

- Add `omni setup trello` for Trello credential guidance and a single configuration command: `omni configure trello --default-board BOARD_ID --api-key API_KEY --api-token API_TOKEN`.
- Make top-level help service-agnostic and move service-specific options behind `setup` and `configure SERVICE --help`.

## Bug fixes

- Correct top-level usage indentation.
- Ensure Trello network errors do not include API credentials from request URLs.

## Breaking changes

- `omni configure trello auth` is superseded by `omni configure trello`. Use the new single configuration command.

## Security

- Network failures from the Trello client now return a credential-safe error message.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`, then use `omni setup trello` to view the current service setup flow.
