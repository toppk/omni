# Omni v0.0.10

## Features

- Teach `omni configure trello --help` how to discover a default board: configure credentials, list visible boards, then store the selected board ID.
- Document the same board-discovery path in the Trello provider guide, including an optional `jq` ID-and-name view.

## Bug fixes

- Make the installer exit successfully without replacing Omni when the installed version already matches the latest release.
- Align installer documentation and website copy with platform selection, no-op behavior, and the non-blocking `~/.local/bin` PATH warning.

## Breaking changes

None.

## Security

None.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`.
- To select a Trello default board after configuring credentials, run `omni observe trello board list`, then `omni configure set trello.default-board-id BOARD_ID`.
