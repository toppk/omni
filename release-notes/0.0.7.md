# Omni v0.0.7

## Features

- Add the initial Tailscale service with action-first device, route, user, DNS, key, and ACL commands.
- Add scoped OAuth-client setup with short-lived generated-token caching and fine-grained scope guidance.
- Add ACL download, validation, access preview, guarded replacement, and private backup support.
- Add `omni observe tailscale key list [--all]` and `omni observe tailscale key get KEY_ID` for non-secret credential metadata audits.
- Add contextual command help, including `omni observe tailscale --help`.
- Add Tailscale provider documentation, an OpenAPI snapshot, and expanded service-onboarding guidance.

## Bug fixes

- Make rejected Tailscale ACL validation return `status: "invalid"` and a nonzero exit status, so validation composes safely in shell and unattended workflows.
- Keep OAuth-client key metadata such as key type, scopes, tags, description, creator, and revoked state in compact key output.
- Correct key-list semantics: `--all` broadens active key types but does not claim to enumerate revoked records.

## Breaking changes

- Tailscale ACL commands use `omni … tailscale acl …`; the earlier unpublished `tailscale policy` paths are not retained as aliases.
- `omni administer tailscale acl set` now requires `--backup BACKUP_FILE`. It validates the candidate, writes a new private backup, and conditionally replaces the ACL using Tailscale's ETag guard.
- Trello card archive is correctly reported as non-reversible because Omni does not provide an unarchive command.

## Security

- Tailscale ACL replacement validates before mutation, creates a `0600` pre-change backup, and uses `If-Match` to prevent silently overwriting a concurrent ACL change.
- Command-registry validation now rejects mutating unattended commands and reversible mutations without an explicit recovery path.
- Tailscale credentials support narrowly scoped OAuth permissions for API tokens, OAuth clients, auth keys, ACLs, DNS, devices, routes, and users.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`.
- For Tailscale, run `omni setup tailscale`, configure a scoped OAuth client, then run `omni describe tailscale` to review the available commands and required scopes.
- Before replacing a Tailscale ACL, provide a new backup path: `omni administer tailscale acl set ACL.hujson --backup acl-before-change.hujson`.
