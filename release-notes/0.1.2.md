# Omni v0.1.2

## Features

- Add `delete trello label delete LABEL_ID`, which completes the board label lifecycle. Board-level label deletion was previously unreachable from the CLI.
- Record what a label deletion destroys, before destroying it. Trello writes no activity entry when a label is attached to a card, so the cards' own label arrays and Trello's `uses` count are the only evidence a label was ever used, and the deletion removes both. `label delete` therefore reads the label and every card carrying it, archived cards included, and reports them as a complete restore recipe: recreate the label, then reattach it with `update trello card label add` using the reported card IDs. A failure reading those cards aborts the deletion rather than leaving an unrecoverable partial restore.
- Add `update trello label set LABEL_ID [--name NAME] [--color COLOR]` to rename or recolor a label in place. The label keeps its ID, so every card carrying it keeps carrying it and nothing has to be re-tagged; only the options supplied change.
- Add `observe trello label color list`, which enumerates every accepted label color, with its hue and shade, without calling Trello.
- Accept Trello's full label palette on `create trello label create` and `update trello label set`: ten hues, each unshaded or shaded, plus `none` for a colorless label. Trello's interface vocabulary (`HUE_subtle`, `HUE_bold`) and its API spelling (`HUE_light`, `HUE_dark`) are both accepted and normalized to what Trello stores. An unsupported color is rejected locally, with the full palette in the error, before any request is sent.
- Add `--scope open|archived|all` to `observe trello card search`, `observe trello card list`, `observe trello list list`, and `observe trello board overview`. Each response reports the scope it read, so an open-only result cannot be mistaken for a complete one, and every list record now carries `closed` so an archived list stays distinguishable inside a mixed result. Archived cards and archived lists were previously invisible: a board with 26 archived lists against 10 open ones presented as a board with 10 lists.
- Add `--archived-list` to `update trello list name set`, which renames an archived list in place. Trello accepts a rename on a closed list, so this replaces unarchive-rename-archive, which left the list briefly live on the board and left it unarchived if the rename failed. The flag asserts the state rather than bypassing the check: without it an archived list is still refused, and with it an open list is refused.

## Bug fixes

- Render a null or empty value as `-` in text output. A Trello label with no color previously printed as a bare `COLOR:` heading, which read as a rendering failure rather than as a value. JSON keeps the original `null`.
- Allow a colorless label to be created and recreated. `--color none` now sends the explicit null Trello requires, so the color that `label delete` reports for a colorless label is a value `label create` accepts. Previously the one attribute the pre-read existed to preserve was, for colorless labels, one that creation could not express.
- Explain a compound `label:` search instead of reporting a bare unknown label. A `label:` query consumes the whole remainder, because Trello label names may contain spaces and colons, so `label:name is:archived` searched for a label named `name is:archived`. The error now says so and points at `--scope`.
- Return open cards that sit in archived lists from `card search`. They were silently dropped by the previous per-open-list enumeration despite not being archived, and their list annotation now shows the archived list.
- Accept options after `BOARD_ID` on board reads, which previously rejected anything past the first positional argument.

## Breaking changes

- None. `observe trello card list`, `observe trello list list`, and `observe trello board overview` gain a `scope` field, and list records gain `closed`; existing fields are unchanged.

## Security

- None.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`.
- Auditing a label, a member, or anything else shared across cards should now use `--scope all`. An open-only read understates what a board contains, and for a label that gap closes permanently once the label is deleted.
