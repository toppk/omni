# Omni v0.1.3

## Features

- Add `omni observe tailscale tag list` to report every tag defined by tailnet policy and its configured owners.
- Add `omni update tailscale credential refresh` to immediately replace Omni's cached OAuth access token without printing token material.

## Bug fixes

- Explain OAuth tag-assignment rejections with Tailscale's exact-set and direct-`tagOwners` requirements, including commands to inspect the credential tags and policy owners.

## Breaking changes

- None.

## Security

- Credential refresh removes only Omni's cached OAuth token and expiry before minting a replacement; it does not reveal token material.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`.
- After changing an OAuth client's scopes or tags, run `omni update tailscale credential refresh` before retrying a Tailscale operation.
