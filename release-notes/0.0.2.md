# Omni v0.0.2

## Features

- Release a single static Linux x86_64 binary (`omni_linux_amd64`) and its SHA-256 checksum instead of a compressed archive.
- Add a checksum-verifying installer at `https://toppk.github.io/omni/install.sh`.
- Add the dark-mode Omni GitHub Pages installation and project site.

## Bug fixes

- None.

## Breaking changes

- Release downloads now use `omni_linux_amd64` rather than the v0.0.1 `.tar.gz` archive. Installers should download the binary directly.

## Security

- The installer verifies the SHA-256 checksum fetched from the same GitHub release before installing the binary.
- The installer defaults to `~/.local/bin` and does not use `sudo`.

## Upgrade notes

- Run `curl -fsSL https://toppk.github.io/omni/install.sh | sh`, or download `omni_linux_amd64` and `omni_linux_amd64.sha256` directly from the release.
