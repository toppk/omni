# Omni v0.1.4

## Features

- Add `just build` for a local `bin/omni` with embedded Git revision and dirty-worktree marker.
- Expand read-only Tailscale evidence with effective OAuth token claims, device posture attributes, and detailed device lifecycle and connection fields.
- Add OAuth tag-delegation preflight and before/after evidence to device tag replacement.

## Bug fixes

- Clarify Tailscale registration provenance, ACL preview API parameter semantics, tailnet selector output, and ACL ETag reporting.
- Hide profile-image URLs from default Tailscale user reports.

## Breaking changes

- `registered_by` is now `registeredBy`, and ACL replacement reports `previous_etag` and `new_etag`.

## Security

- None.

## Upgrade notes

- Install or upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`.
