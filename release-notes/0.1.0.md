# Omni v0.1.0

## Features

- Expand Trello to support a practical board workflow: bounded card search and collection reads, labels, members, comments and reactions, checklists, activity, due-date completion, board descriptions, and safe archive/unarchive flows.
- Add Trello attachment lifecycle commands: list, bounded download to an explicit local file, upload, and delete. Downloads use OAuth request headers so credentials are not placed in the attachment URL.
- Let `create trello card create` accept repeated `--label` and `--member` options. Omni validates those IDs against the destination board before creating the card.
- Add local `label:NAME` filtering to `observe trello card search`, with complete `matched`, `searched`, and `truncated` counts so a bounded result never silently looks complete.
- Make text the default service-output format for people while retaining canonical JSON with `--format json` or `OMNI_OUTPUT=json`. Card collections now render as compact scan tables with progress, labels, assigned-member initials, and date-only due values.
- Add Task-based developer shortcuts: `task check`, `task build`, and interactive `task release`, which computes a patch, minor, or major version from the latest reachable release tag and performs the guarded tag-and-release workflow.

## Bug fixes

- Refuse Trello mutations of archived cards or lists before writing, instead of allowing changes to hidden archived work.
- Return archived card IDs when archiving all cards in a list, making the documented unarchive reversal executable.
- Preserve checklist progress, labels, member assignments, and other task-relevant fields in compact Trello responses.
- Correct Trello card-search label handling, attachment authentication, and text output so results are complete, actionable, and readable in a terminal.

## Breaking changes

- Service commands now default to text output. Scripts and agents that require the stable machine-readable contract should pass `--format json` or set `OMNI_OUTPUT=json`.

## Security

- Attachment download accepts only Trello-hosted uploaded attachments, requires an explicit new output file with restrictive permissions, enforces a 25 MiB limit, and refuses to overwrite existing files.
- Trello card creation fails closed when a requested label or member is not on the destination board, preventing silent partial setup.
- The release helper requires a clean `master`, matching release notes, a passing quality gate, and a new tag before publication.

## Upgrade notes

- Install or upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`.
- If you parse Omni output, update invocations to include `--format json` or set `OMNI_OUTPUT=json`.
- Task is optional and development-only. See [DEVELOPING.md](../DEVELOPING.md) for installing it and using the guarded release workflow.
