# Omni v0.0.9

## Features

- Publish single-binary releases for Linux x86_64, Linux ARM64, macOS Intel, and macOS Apple Silicon.
- Make `install.sh` select the matching supported operating-system and architecture asset automatically.

## Bug fixes

- Disable Go dependency caching in the release workflow because Omni intentionally has no external modules or `go.sum`, eliminating the misleading cache-restore warning.
- Warn, without failing or changing shell configuration, when `~/.local/bin` is not on `PATH`.
- Update release and Pages checkout actions to the Node 24 runtime.

## Breaking changes

None.

## Security

- The installer continues to download the matching release checksum and verify it before installation on every supported platform.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh` on supported Linux or macOS machines.
- If the installer warns that `~/.local/bin` is not on `PATH`, add that directory in your shell configuration before invoking `omni` by name.
