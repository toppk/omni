# Omni v0.0.5

## Features

- Add service-level capability discovery with `omni describe SERVICE` and `omni describe SERVICE --format=json`.
- Add stable operation IDs, descriptions, response descriptions, credential requirements, effect metadata, and implementation status to the command schema.
- Make `omni describe` list available services and the commands used to enumerate their capabilities.

## Bug fixes

- None.

## Breaking changes

- `omni describe` now presents the service discovery overview instead of a flat list of every operation. Use `omni describe SERVICE` for an operation catalog.

## Security

- Capability output distinguishes implemented operations from planned operations so agents do not infer unavailable functionality.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`, then run `omni describe trello --format=json` to inspect the Trello capability catalog.
