# Omni v0.0.11

## Features

- Render service responses as compact human-readable text by default, including tables for collections and labeled records for individual results.
- Add `--format text|json` to service commands. It may appear anywhere after the effect and is presentation-only.
- Add `OMNI_OUTPUT=text|json` to choose a process-wide default output format.

## Bug fixes

- Derive text and JSON output from the same compact response value so the human renderer cannot diverge from the machine contract.

## Breaking changes

- Service commands now default to text instead of JSON. Agents, scripts, and other machine consumers should pass `--format json` or set `OMNI_OUTPUT=json`.

## Security

- Output-format selection is accepted only after the effect token, preserving Omni's effect-first command contract and preventing a presentation flag from obscuring an operation's classification.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`.
- Update automation from `omni observe SERVICE …` to `omni observe SERVICE … --format json`, or export `OMNI_OUTPUT=json` for the calling process.
