# Omni v0.1.1

## Features

- Make Trello onboarding start with `omni configure trello`; the command now displays its local guide without requiring `--help` and without creating configuration files.
- Make Trello's manual credential path explicit for agent use: create the minimal Power-Up for an API key, open its API Key tab, click **Generate a Token**, approve access, and configure Omni with the resulting user token.

## Bug fixes

- None.

## Breaking changes

- None.

## Security

- Clarify that the Power-Up app secret is not required or accepted by Omni's current Trello setup path.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`.
- Re-run `omni setup trello` to see the updated credential guidance.
