# Omni v0.0.6

## Features

- Redesign `omni describe trello` as an `OMNI-TRELLO(1)` service manual with NAME, SYNOPSIS, DESCRIPTION, COMMANDS, CONFIGURATION, and SEE ALSO sections.
- Document each runnable Trello command's positional arguments, options, behavior, and response in the service manual.
- Add argument and option metadata to the JSON capability catalog.

## Bug fixes

- Stop listing unimplemented operations as runnable commands in capability discovery.
- Return empty JSON arrays instead of `null` for operations without arguments or options.

## Breaking changes

- Human `omni describe trello` output no longer displays internal operation IDs or implementation-status labels. Use `--format=json` for machine-oriented metadata.
- Unimplemented Tailscale and Trello board-creation commands are no longer advertised by `omni describe`.

## Security

- Capability discovery now reflects only operations that Omni can execute, reducing the chance of an agent attempting an unavailable command.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`, then run `omni describe trello` for the complete Trello reference manual.
