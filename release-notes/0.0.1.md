# Omni v0.0.1

## Features

- Initial native Trello CLI integration for board, list, and card operations.
- Action-first command grammar with runtime policies, structured command discovery, and local credential storage.
- Trello configuration registry with configurable API endpoint and default board ID.

## Bug fixes

- None; this is the initial release.

## Breaking changes

- None; this is the initial release.

## Security

- Credential directory and file are restricted to owner access (`0700` and `0600`).
- Read-only policy blocks mutation before any provider request is sent.

## Upgrade notes

- Linux x86_64 only for this release. Download the release binary and make it executable, or use the future Pages installer after a release that includes the direct binary asset.
