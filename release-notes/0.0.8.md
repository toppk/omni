# Omni v0.0.8

## Features

- Expand Trello from basic board and card access into a workflow-oriented service with list, card, label, member, checklist, comment, reaction, activity, search, and attachment commands.
- Add board-description updates, due-date completion updates, checklist-item renaming, attachment metadata listing, bulk card reads, and bulk card archive with returned card IDs for recovery.
- Add checklist creation, item creation, completion updates, deletion, and reads so cards can carry and maintain milestone checklists end to end.
- Add Trello card search, card-list reads, activity streams, comments and reactions, label and member management, and list positioning and lifecycle commands.
- Make root help service-oriented: it shows each service's local configuration readiness and points directly to `omni describe SERVICE`.
- Add a dated Trello OpenAPI snapshot and expanded setup guidance with the API overview, application-management walkthrough, and direct API-key page.

## Bug fixes

- Refuse mutations of archived Trello cards and lists before writing, with an error that directs callers to unarchive first.
- Return `archived_card_ids` from bulk card archive so its documented reversal can be performed without separately recording every ID.
- Include comment reactions in comment reads and card review, return `comment_id` from reaction creation, and explain that a `commentCard` activity ID is the comment ID.
- Keep card checklist progress and attachment counts as compact workflow signals while removing unneeded provider fields from cards, lists, activities, and boards.
- Render variadic command arguments accurately in service help and provide a direct `use --format=json` hint for the `--json` near miss.

## Breaking changes

- Compact Trello board responses no longer include `labelNames`. Use `omni observe trello label list BOARD_ID`, which supplies the usable label ID, color, and name.
- Trello checklist item updates now identify their parent as `CHECKLIST_ID ITEM_ID`; list renaming uses `--name NAME`.
- Trello card archive is now correctly reversible through `update trello card unarchive CARD_ID`.

## Security

- Extend registry and command coverage so Trello mutations retain explicit effect boundaries, archive guards, recovery metadata, bounded reads, and stdout/stderr failure behavior.
- Document the trust boundary between Omni's declarative command contract and untrusted provider content, including user-authored Trello text.
- Add provider-shaped fixture guidance and harmless live-verification guidance for catching differences between an API's documented behavior and its real responses.

## Upgrade notes

- Upgrade with `curl -fsSL https://toppk.github.io/omni/install.sh | sh`, then run `omni describe trello` to review the expanded command surface.
- Run `omni setup trello` to configure an API key, token, and optional default board. Existing Trello credentials and configuration continue to work.
- If you consume compact board JSON, replace `labelNames` usage with `omni observe trello label list BOARD_ID`.
